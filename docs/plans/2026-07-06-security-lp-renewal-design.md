# セキュリティLP刷新 設計ドキュメント

- 日付: 2026-07-06
- 対象: `/security/index.html`, `/security/style.css`, `/security/main.js`
- ステータス: 設計承認済み

## 目的

導入実績（信用金庫・SIerへの直接販売）を反映し、訴求軸を「スタートアップ向けの安価な診断」から「金融機関・SIerが選んだ、AIレッドチーム経験者による手動診断」へ転換する。既存のセクション構成・フォーム・アンカーリンクは維持し、必要最小限の差分で改修する。

## アプローチ

3案を比較し、A案を採用。

| 案 | 内容 | 判断 |
|---|---|---|
| A. 最小差分改修（採用） | CSS変数の差し替え＋局所的なHTML編集。セクション構成・フォーム・アンカーを完全維持 | 指示書の前提と一致、リスク最小 |
| B. style.css 全面再設計 | デザイントークンから再構築 | 回帰リスク大、スコープ過剰 |
| C. セクション再構成 | 情報設計から見直し | スコープ外（指示書「やらないこと」）に抵触 |

## 確定した論点（ユーザー確認済み）

1. **アクセントカラー**: 現行のスカイブルー #38bdf8 を落ち着いたティール #35B5AE へ転換。--c2 は #9BA8DC（インディゴ減彩）。--c4 エメラルドと深刻度バッジの赤・橙は機能色として維持。
2. **比較テーブル**: sr-only（SEO専用）だった診断サービス比較テーブルを可視化。モバイルは横スクロール＋スクロールヒント表示。
3. **フローティングCTA**: 維持。「CTA 3箇所」はページ内静的CTAの数と解釈。

## 1. コピー改修

## 2. デザイン改修

### 2-1. カラー

- `--c1: #38bdf8 → #35B5AE` / `--c1b: #7dd3fc → #6FCFC8` / `--c2: #a5b4fc → #9BA8DC`
- `--c4: #34d399` 維持、CRITICAL赤・HIGH橙 維持（機能色）
- 直書きの `rgba(56,189,248,…)` → `rgba(53,181,174,…)`、`rgba(129,140,248,…)` → `rgba(155,168,220,…)`、ボタングラデの `#0ea5e9` → `#2A9D96` に一括置換
- セクション背景の交互リズム調整: free-diag を bg→bg2、faq を bg2→bg、contact を bg→bg2 に変更し濃淡交互を回復

### 2-2. タイポグラフィ

- 日本語見出し: weight 600–700（hero-catch の 900→700）、`letter-spacing: 0.02em`
- Google Fonts: Noto Sans JP から 900 を外し 600 を追加
- 英字ラベル `.section-label`: 12px→11px、letter-spacing 6px→4px
- 本文行間: 1.8 前後に統一（body 1.7→1.8、個別の 1.85〜2.0 を 1.8 へ。ターミナル・コード表示は除外）

### 2-3. 演出の抑制

- ターミナル `balcony_scan.sh` は維持。タイプライター 220ms/行→280ms/行、カーソル点滅 1s→1.2s
- H1グリッチ: 7秒ごとの無限リピート → 初回1回のみ
- 背景パーティクル: 160個/opacity 0.75 → 100個/0.5

### 2-4. バッジデザイン

1pxボーダー＋わずかな背景差（rgba(255,255,255,0.02)）、影なし。ホバーでボーダーがティールに変わるのみ。ロゴ壁風の装飾はしない。

### 2-5. 余白とCTA

- セクション余白: 120px→160px（1024px時 100→132px、640px時 72→96px）
- ページ内CTA 3箇所: ①ヒーロー（既存）②バッジ直後（新設）③FAQ直後（新設、#contact アンカー）
- フローティングCTAは維持

### 2-6. モバイル

- バッジは縦積み、タップ領域44px以上
- 比較テーブルを診断サービスセクション末尾に可視化。`overflow-x:auto`＋モバイルのみスクロールヒント表示

## 3. メタ情報更新

指示書のコピー（約60文字）は og:description の100文字以上要件（SITE_RULES 4.2）を満たさないため、以下の拡張版（108文字）を meta description / og:description / twitter:description / JSON-LD description に共通適用:

> 金融機関・SIerへの導入実績。OpenAI・Grokのレッドチーム経験者による手動セキュリティ診断。Webアプリ・API・クラウド・生成AI/LLMシステムに対応し、再現手順と修正方針を明記した報告書を提出します。

title タグは現行維持。

## v2: ライト基調への全面デザイン刷新（2026-07-06 追記）

v1（ダーク基調・最小差分）のプレビュー後、「ごちゃごちゃしてわかりづらい」とのフィードバックを受け、デザインを全面刷新。ユーザー確認により以下を決定。

- **基調**: ダーク → ライト（白背景 × ネイビー #15263A × ティール #0E7C74）。コーポレートサイトのライトトーンと調和
- **技術演出**: ヒーローのターミナル（ダークウィンドウ）のみ残す。AIセクションのコードカード・タグ行は削除、無料診断の所見カードは「深刻度バッジ＋所見名」の簡素な行に変更

### 撤去した装飾

パーティクルcanvas、ノイズオーバーレイ、アンビエントグラデーション、ヒーローグロー、グリッチエフェクト、装飾背景番号（01〜04）、巨大背景文字「AI」、カード内グロー/背景装飾、セクション区切りのグラデーション線

### 新デザインの原則

- カードはすべて白背景＋1pxボーダー（#E3E9ED）＋角丸10px、影なし。ホバーはボーダー色がライトティールに変わるのみ
- 背景は白と #F4F8F8 の2段を厳密に交互（hero→trusted(淡)→who(白)→…→contact(淡)→footer(濃紺)）
- 深刻度バッジは機能色を維持（ライト用に赤 #B3261E / 橙 #9A5B00 / ティールへ調整）
- フッターのみダークネイビー（#131F30）でターミナルと呼応させるブックエンド構成
- main.js からパーティクル・グリッチ・AIカード整列の各コードを削除
